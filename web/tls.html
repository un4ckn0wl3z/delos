🔒 Secure connection

Browsers only allow direct in-browser playback (WebCodecs) on a secure https:// page. This server speaks both http and https on the same port — the apps keep working either way.

Remove the browser warning (optional)

The server makes its own certificate, so browsers warn the first time — you can click Advanced → Proceed and playback works. To get rid of the warning for good, install this server's certificate once on each device:
⬇ Download certificate

The certificate is limited to this server's own address (), so it can't be used to impersonate any other website.

Windows (Chrome, Edge)
  1. Open the downloaded streammkv-ca.crt → Install Certificate…
  2. Choose Current User → Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  3. Finish, confirm the security prompt, then restart the browser.
macOS (Safari, Chrome)
  1. Double-click the file — it opens Keychain Access and adds it to login.
  2. Double-click the Delos … CA entry (older servers: StreamMKV … CA) → Trust → When using this certificate: Always Trust.
  3. Close the window (enter your password), then reload this page.
iPhone / iPad
  1. Open this page in Safari, tap Download certificate → Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on Delos … CA (or StreamMKV … CA).
Android (Chrome)
  1. Download the certificate.
  2. Settings → Security (and privacy) → More security settings → Encryption & credentials → Install a certificate → CA certificate → pick the file.
  3. Restart Chrome.
Linux (Chrome) · Firefox (any system)
  1. Chrome: open chrome://certificate-manager → Local certificates → Custom → Import.
  2. Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import → tick “Trust this CA to identify websites”.
